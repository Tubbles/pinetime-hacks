# Suggestions (not yet To Dos)

Everything below was noticed during work and written down so it isn't lost. These are optional ideas and observations — candidate To Dos, not committed work. Nothing here is planned or promised; an item only becomes an actual To Do when deliberately promoted into `TODO.md`.

- Generalize the "time of next event" corner to other event sources once the Napper path works: next phone alarm, Google Calendar (via phone connection). Mentioned by the user at project start as explicitly out of scope for now.
- True padlock glyph for the wrist-raise lock indicator: v1 reuses `Symbols::shieldAlt` (U+F3ED, already in `jetbrains_mono_bold_20`); a real padlock means adding U+F023 to the FontAwesome range in `InfiniTime/src/displayapp/fonts/fonts.json` and regenerating with `fonts/generate.py`. Optional polish, deferred to keep v1 font-neutral.
- Watch timer could adopt the remaining duration of a phone-side paused timer: today a paused phone timer arrives as ClockSync "stopped" with `value_ms` = remaining, and the firmware only calls `StopTimer()`, discarding `value_ms`. Presetting the Timer screen's counters from it would make resume-on-watch seamless. Noticed during the 2026-08-02 review; deferred as beyond the review's contract.
- Latin Extended-A for notifications: JetBrains Mono Bold also covers 0x100-0x131 (and fc-query shows more beyond), so Polish/Czech/Turkish letters could join the Latin-1 block added for Swedish by extending the `jetbrains_mono_bold_20` range in `InfiniTime/src/displayapp/fonts/fonts.json` further (~30 B of flash per glyph). Deferred: the ask was Swedish, and each block should be weighed against the 474 KB flash budget (81.87% used after Latin-1).
- A small settings UI in the Clock fork for the clocksync prefs (`clocksync_watch_mac`, `clocksync_gadgetbridge_package`, `clocksync_dialer_package`): today they are BuildConfig-seeded/hand-set (`phone/clocksync/README.md` section c.3). Noticed while adding the third pref for the dialer package.
- Show the caller (name/number) on the InCall screen: Gadgetbridge T currently writes only a 1-byte active/ended flag to `00080002`; a richer frame (or reusing the incoming-call alert text) could carry the caller into the InCall title. Noticed while implementing call-state forwarding; deferred to keep the frame trivial.
- Upstream InfiniTime PR candidates from the 2026-08-03 DFU forensics (`doc/LOG.md`): the PersistBond stack-overflow fix trio (static buffers in `NimbleController.cpp`, host task stack size in `nimble_port_freertos.c`, `configCHECK_FOR_STACK_OVERFLOW 2`); the PersistBond CCCD read `idx = peer_count` bug; the MusicService duplicate `characteristicDefinition[6]`/`[7]` both registering `msTotalLengthCharUuid` (kept locally for stock-handle compatibility); and the Service Changed announcement after firmware updates. All are upstream-relevant, none are specific to this fork.
- Upstream Gadgetbridge PR candidate: the multi-target BLE Intent API (`c288c7894` in the GB T fork) — the package filter as a comma-separated list with per-package explicit broadcasts. Generic, removes the forwarding-hub workaround for any multi-consumer setup; empty setting preserves upstream behavior.
